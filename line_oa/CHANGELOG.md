# 未發布

- 修正特殊別名撤銷失效：改以 Map 儲存與查找，`__proto__` 等字串只代表明確建立的別名；刪除後有效 API Key 也無法再以該別名發送。保留既有 JSON 與舊格式遷移相容性。
- 修正圖片暫存總量競態：容量檢查與寫入排入同一序列，避免併發超過 20 MiB；寫入失敗清除部分檔案，無法確認容量時拒絕寫入。
- QR 上游回應逐塊計算已解碼大小，超過 2 MiB 即取消讀取與連線；不依賴 Content-Length，也不先完整讀入過大內容。

- 登入及登入後請求統一瀏覽器識別：amd64 使用 Windows Chrome、aarch64 使用 macOS Chrome。登入來源維持實際 LINE 官方流程；通知顯示名稱由 LINE 決定。

- 背景 Session 驗證改為發送後閒置 30 分鐘加隨機 0～30 分鐘，不再固定每 5 分鐘或啟動時立即查詢。
- 文字與圖片實際發送後重新計時，包含結果不明；本機拒絕的請求不重設，持續閒置則每次重新抽取等待時間。
- 發送前驗證、手動測試及確認過期後停止向 LINE 查詢的行為保留；狀態 API 繼續只讀取記憶體。
- 啟動後以啟動時間作首次計時基準；重啟後不沿用舊排程。

# 0.1.6
